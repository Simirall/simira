```txt
pnpm install --frozen-lockfile
pnpm dev
```

Open [http://localhost:5667](http://localhost:5667) for local development.

```txt
pnpm exec waku router typegen
pnpm typecheck
pnpm build
pnpm start
```

`pnpm start` previews the built Cloudflare Worker locally. Deployment uses the
Wrangler configuration generated by the build:

```txt
pnpm exec wrangler deploy --dry-run --config dist/server/wrangler.json
pnpm deploy
```

[For generating/synchronizing types based on your Worker configuration run](https://developers.cloudflare.com/workers/wrangler/commands/#types):

```txt
pnpm cf-typegen
```

Pass the `CloudflareBindings` as generics when instantiation `Hono`:

```ts
// src/index.ts
const app = new Hono<{ Bindings: CloudflareBindings }>();
```
